# מדריכי המתי״א

מדריכי הפעלה קצרים, שלב אחרי שלב, עם סימון מדויק של כל מקום שצריך ללחוץ עליו.

**הדף החי:** https://neshamalevy-design.github.io/matia-guides/

## המדריכים

| מדריך | תיקייה |
|---|---|
| העלאת יומן מקובץ ICS ל-Outlook | `ics-outlook/` |

## מבנה

כל מדריך יושב בתת-תיקייה משלו עם `index.html` יחיד ועצמאי — צילומי המסך
מוטמעים בתוך הקובץ, כך שאין תלות בקבצים חיצוניים ואפשר גם לשלוח אותו כקובץ בודד.

`index.html` בשורש הוא דף המפתח שמקשר לכולם. מדריך חדש = תת-תיקייה חדשה
ושורה נוספת בדף המפתח.

## פרטיות

צילומי המסך עברו טשטוש של פרטים מזהים — שמות אנשים, כתובות מייל,
כותרות הודעות ותוכן אירועים ביומן.
