# כלי הבנייה

התיקייה הזו מייצרת את המדריכים. **הקבצים כאן הם המקור — לא לערוך את
`ics-outlook/index.html` ישירות.** הוא קובץ בן ~700KB שיש בתוכו שבעה
צילומי מסך מקודדים, ועריכה ידנית שלו כמעט בלתי אפשרית.

## מה נמצא כאן

| קובץ | תפקיד |
|---|---|
| `build_guide.py` | **הראשי.** מייצר את `../ics-outlook/index.html` |
| `img/` | שבעת צילומי המסך, אחרי טשטוש הפרטים המזהים |
| `print-layout.html` | פריסת ההדפסה — ממנה נגזרים ה-PDF וה-Word |
| `make_marked.py` | מייצר את `marked/` — צילומים עם ההדגשות צרובות בתוכם |
| `build_docx.py` | מייצר את קובץ ה-Word מתוך `marked/` |

## לשנות משהו במדריך

טקסטים, סדר השלבים ומיקומי ההדגשות — הכול יושב במבנה `STEPS` בראש
`build_guide.py`. אחרי עריכה:

```bash
cd _build
python build_guide.py
```

זה כותב מחדש את `../ics-outlook/index.html`. קומיט ודחיפה, ו-GitHub Pages
מתעדכן תוך דקה-שתיים.

## מיקומי ההדגשות

כל הדגשה מוגדרת כך:

```
(left, top, width, height, מיקום-התגית, הכיתוב, צורה)
```

ארבעת הראשונים הם **אחוזים מגודל התמונה**, ולכן ההדגשה נשארת במקום
בכל גודל מסך — גם בטלפון. `מיקום-התגית` קובע לאן נצמד עיגול המספר:
`tl` / `tr` מעל המסגרת, `bl` מתחתיה, `out-s` / `out-e` לצדדים. אם התגית
מסתירה טקסט חשוב בצילום — מזיזים אותה לצד פנוי.

`צורה` ריק = מלבן, `circle` = עיגול.

## לייצר PDF או Word

```bash
cd _build
python make_marked.py     # דורש Edge מותקן
python build_docx.py
```

ל-PDF: לפתוח את `print-layout.html` בדפדפן ולהדפיס לקובץ, A4 לרוחב.
הפריסה מכוילת כך שכל שלב נכנס בדיוק לעמוד אחד.

## פרטיות

הצילומים ב-`img/` עברו טשטוש בלתי-הפיך של שמות אנשים, כתובות מייל,
כותרות הודעות ותוכן אירועים ביומן.

**הצילומים המקוריים לפני הטשטוש אינם בריפו הזה ואסור להעלות אותם** —
הריפו ציבורי. הם נשארו מקומית בלבד, בתיקיית העבודה שממנה נבנה המדריך.

`marked/` ותוצרי ה-PDF/Word אינם נשמרים בגיט (ראו `.gitignore`) — הם
נגזרים ונוצרים מחדש בכל פעם.
